# 做了个「麦麦不忘」：把感兴趣的麦当劳活动放进日历

想集中查看早餐上新、咖啡新品或联名周边信息，可以把相关活动日历加入平时使用的日历客户端。「麦麦不忘」在 Codex 辅助下开发，将麦当劳中国官方 MCP 返回的活动日历整理成网页和可订阅的 ICS，方便浏览与订阅。

普通使用者直接打开网页就能看，不用申请 MCP Token，也不用配置开发环境。页面保留来源原文，可以搜索活动、展开查看内容，也能切换早餐、咖啡、联名周边三个主题。比如只想关注厚松饼堡和早餐相关信息，就选早餐；想看看麦咖啡新品，就选咖啡；关注棒球帽、徽章等周边，可以选联名周边。主题按标题和原文关键词筛选，不保证覆盖所有相关活动。

选好主题后，复制对应订阅地址，添加到支持 URL 订阅的日历客户端即可。网页的自由搜索和日期开关只改变下方列表，不改变订阅内容。也可以下载 ICS 导入，留一份当时的快照；后续想持续接收变化，请使用订阅方式。

更新由项目侧处理：GitHub Actions 每六小时尝试查询、校验并生成公开日历，失败时保留最后成功的数据。页面会展示最近成功查询时间。实际调度、客户端刷新都可能延迟，提醒通知和提醒时间由你的日历客户端控制。

有一点需要先说明：日程日期是官方日历的展示日期，不代表当天开售或活动截止；同一活动可能在多个展示日出现。参与条件、价格、供应情况仍请核对官方原文和实时渠道。

这是麦当劳程序员创意开发大赛的独立参赛作品，非麦当劳官方产品。代码已开源。如果你实际用下来觉得有用，欢迎自愿 Star；也欢迎在仓库反馈订阅兼容性、数据理解或使用中的问题。
