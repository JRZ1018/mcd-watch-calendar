A LITTLE HELP

留在你的日历里。

01

订阅，持续接收更新

复制订阅地址，在日历客户端的“添加订阅日历”或“从 Web 订阅”中粘贴。支持订阅的客户端也可直接点击上方按钮。

02

导入，留一份快照

下载 ICS 后导入 Outlook、Apple 日历等。单次导入不会自动获取后续更新；提醒时间请在客户端设置。

03

看一眼更新时间

服务每六小时尝试从官方 MCP 更新，调度和客户端刷新可能延迟。查询失败时保留最后成功数据。
